# Колко каси да отворим?

Симулатор на опашки пред каси. Курсова работа на тема „Разработване и изследване на
програмни решения“.

Сайтът симулира работен ден в магазин с няколко каси при три вида опашка (една обща,
отделни с избор на най-късата, отделни със случаен избор) и намира колко каси са нужни,
за да е средното чакане под зададена стойност.

## Стартиране

```
python -m venv .venv
source .venv/bin/activate     (Windows: .venv\Scripts\activate)
pip install -r requirements.txt
python run.py
```

Сайтът се отваря на http://localhost:5050

Експериментите от курсовата работа се пускат с `python experiments.py`. Таблиците излизат
в конзолата, а графиките се записват в `results/`.

## Структура

```
app/
  models/        симулацията и изчисленията
  controllers/   страниците на сайта (Flask blueprint)
  views/         графики и форматиране
  templates/     HTML шаблони
  static/        CSS и анимацията
run.py           стартиране на сайта
experiments.py   експериментите
```
